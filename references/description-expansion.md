# 简短描述扩写规范

当用户给出的是一句或两句画面概念，而非明确的最终画面说明时，先帮助其发现可选叙事，而不要替用户过早决定所有细节。

## 第一阶段：方向菜单

给出 2–5 个可选方向，每项 1–2 句。每个方向保留用户已经说出的主体、场景和核心氛围，只改变有意义的视觉决策。

可变化的维度包括：

- **画面尺度**：人物中小、环境主导；或更亲密的中景；或极小人物面对巨构空间。
- **光线与时间**：冷白晨光、横切的黄昏暖光、阴天窗光、暴风前的天际光等。
- **空间与材质**：生活化旧设施、克制的工业结构、玻璃/水面反射、自然物与人工物的比例。
- **叙事关系**：等待、途经、短暂停顿、坠落、观察、离开、城市仍在运转而人物静止。
- **镜头语言**：横向宽银幕 35–50mm 环境叙事、竖向超广角巨构尺度、隔着玻璃观察、平静对称或克制的倾斜。

方向菜单不可偷换用户已给的事实。例如用户没有说“白猫”，不能默认加入白猫；用户没有说高空，也不应擅自改为坠落场景。

## 第二阶段：完成扩写

在用户选定方向后，写成一段可直接作为图像创作简报的中文叙述。通常约 300–700 个汉字；复杂巨构或多层环境可以更长，简单近景可更短。段落应自然连贯，使用具体可见的名词、动词和光线关系，不使用“超高质量、杰作、8K”一类空泛词作为正文。

建议按以下逻辑自然展开，而不是标号罗列：

1. **人物与姿态**：只补足能让人物可视化的年龄感、体态、发型、服装轮廓、动作与情绪。保持日系动画人物的图形化脸部与头发；服装细节先说明大轮廓，再添加少量功能性或叙事性点缀。
2. **人物和空间的关系**：说明人物位于何处、比例多大、如何被空间包围，以及是否与一个视觉锚点形成关系。
3. **可信环境**：使用少量具体但互相关联的建筑、家具、设备、植物、水面或生活痕迹，让地点成立。细节应说明使用、年代、尺度或运行状态；不要无差别堆砌螺丝、反光、管线和装饰。
4. **光影与色彩**：指出主光来源、方向、照亮的局部、深色区域保留的色相信息，以及一组主色和一处克制强调色。避免“全部发亮”或“所有暗部纯黑”。
5. **镜头与层次**：明确横/竖画幅、人物位置、镜头大致焦段、前中后景、景深与透视。让环境承担主要空间叙事时，人物通常全身且中小比例。
6. **情绪与悬念**：用一句收束为一个未被解释的故事中段，例如等待、失重、重逢前、城市依然运行而人物短暂停顿。保持克制，不把情绪解释得过满。

## 质量检查

完成扩写后，检查：

- 是否仍然忠实于用户的原始简述？
- 是否至少有一个明确的画面冲突或对照（如冷暖、自然/工业、静止/运转、微小人物/巨大空间）？
- 环境细节是否服务于场景和叙事，而非只表现“很精细”？
- 人物是否是日系动画人物，而不是写实人像或 3D 雕塑？
- 画面是否保留能用于下一步生成的构图、光线和色彩信息？

随后再依据此段扩写使用 `prompt-template.md`、`modular-prompt-library.md` 与 `tonal-parameters.md` 构建实际提示词和参数。
