# 扩写后的电影方法匹配

在完成中文场景扩写后、写最终提示词前使用本参考。目标不是套用固定风格，而是从扩写中识别故事与空间的真实需要，选择最少但正确的镜头、景深和光影方法。

## 先写方法卡

从扩写中提取下列字段，每项只选最能决定画面的值。不要为了填表虚构用户未给出的物件、剧情或角色设定。

```text
叙事状态：等待 / 观察 / 离开 / 到达 / 临界 / 被吞没 / 静止中的流动 / 其他明确动作
主体角色：叙事锚点 / 环境主角 / 亲密情绪焦点
空间形态：巨构或开阔 / 有纵深的日常空间 / 中轴建筑空间 / 有观察边界的空间 / 动作场景
构图方法：从下表选一项
景深方法：从下表选一项
光影方法：从下表选一项
执行路线：直接终稿 / 构图搜索 / 分轮迭代
```

方法卡应直接来自扩写：例如“人物在风暴前的巨型窗前等待”自然指向环境压迫型远景、深或中景深、暗室亮窗，而不是人物近景和泛光柔焦。

## 匹配构图与摄影机

| 扩写中出现的关系 | 选用的方法 | 写入提示词的关键约束 |
| --- | --- | --- |
| 巨大天空、海面、城市、建筑或人物被环境吞没 | **环境压迫型远景** | wide/extreme wide，人物小，环境主导，高负空间；低机位或平视仅在其增强尺度时使用。 |
| 花、树林、街道、室内物件等形成连续前中后景 | **景深层次型中景** | 三层或四层空间，前景遮挡，中景主体最清晰，背景可读但更柔化。 |
| 大厅、走廊、车站、教堂等具有单点透视与仪式感 | **中轴舞台型** | 中轴或克制对称，地面、家具、结构或灯光形成引导线；只有故事要求秩序或对峙时才让人物居中。 |
| 人物的孤立、离开、观察或环境空白比动作更重要 | **偏置叙事型** | 三分法或边缘主体，大量负空间，环境解释人物处境；避免角色海报式居中。 |
| 场景本身包含门、窗、玻璃、家具、植物或洞口这一观看边界 | **框景观察型** | 让边界成为前景框景或轻度遮挡，保留观察距离；不能为了框景凭空增加道具。 |
| 跳跃、奔跑、坠落、浪、水流或强风是叙事触发点 | **动势环境镜头** | 选择能读出动作路径的广角或低机位；用一至两项环境互动表现动势，不堆叠特效。 |

若有两种方法都合理，先选能最清楚说明“人物与环境为何在此刻产生关系”的一种。不要混合两种互相冲突的摄影机逻辑。

## 匹配景深与空间层级

| 扩写中的需求 | 景深方法 | 约束 |
| --- | --- | --- |
| 尺度、地理关系、巨构或动作路径必须清楚 | **中/深景深** | 背景保持可读，透视和环境层次优先；不使用无意义的大面积散景。 |
| 需要经过遮挡、窥视、花丛、室内物件或雨夜灯光建立距离 | **三层浅至中浅景深** | 模糊前景、清晰主体、可读而柔化的背景；主体不是唯一可见信息。 |
| 对称建筑、走廊或多人关系依赖全景调度 | **中景深** | 前中后层次清楚，焦点在关系而不只在脸部。 |
| 亲密的手势、眼神或一件叙事物件决定故事 | **选择性浅景深** | 仅在用户明确需要亲密焦点时选用；仍要保留足够环境线索。 |

所有方法都要避免全画面同样锐利、或只把背景简单糊掉的“海报虚化”。

## 匹配光影、阴影与反射

| 扩写中的故事状态或空间 | 光影方法 | 约束 |
| --- | --- | --- |
| 威胁、等待、巨大空间、风暴前或从暗处望向亮处 | **低调方向光** | 入口、窗、月、天空裂隙或单一实景光作为主光；大面积深色有色阴影保留结构。 |
| 离开、边界、回望、风与水的动作 | **侧逆光/轮廓光** | 用窄亮边或水面、玻璃反射切出动作轮廓；高光只落在叙事边缘。 |
| 温柔但有层次的日常、树影、窗边或花海 | **受控柔和方向光** | 柔和的是过渡，而非全局曝光；保留明确的主光方向和一块深色结构。 |
| 大厅、车站、室内外对照 | **亮入口 + 暗内部** | 入口或窗外成为高光，室内形成深色容器；地面或玻璃反射只在引导视线时保留。 |
| 静水、雨、玻璃、金属或湿地面天然参与故事 | **选择性反射** | 反射重复或延长关键光线、人物路径或视觉锚点；不把每个表面做成镜面。 |

默认保持高对比、暗部有信息、近白高光节制。若用户明确要求高调画面，仍需保留可读的方向性和阴影层次。

## 选择执行路线

| 情况 | 路线 | 工作方式 |
| --- | --- | --- |
| 用户给出清晰的主体、场景、动作、镜头或情绪，且一个方法卡能稳定解决 | **直接终稿** | 将方法卡转为一张完整正向提示词；不为形式制造多轮。 |
| 主体比例、摄影机位置、负空间或构图关系尚不明确 | **构图搜索** | 先提供或生成少量构图候选；每个候选只改变主体比例、位置、负空间、遮挡、机位或构图模式中的一项。先选镜头，不讨论细节。 |
| 用户要继续优化一张图，或构图正确但空间、光影或细节有具体问题 | **分轮迭代** | 依序处理：构图 → 景深/空间层级 → 光影/阴影/反射 → 细节。每轮只动一至三个该轮变量，后续轮次明确保留此前锁定的构图、机位、主体比例、光向与深度结构。 |

不要承诺固定数量的图片或轮次；根据用户的目标、图像工具能力和上一轮结果决定是否继续。除非用户要求多版本，单轮只给一个最有依据的下一步。

## 每轮诊断

每次生成后，只检查与当前路线和轮次有关的问题，并把下一步限定在一至三个变量：

- 构图：主体比例与位置、负空间、透视、环境是否在讲故事，还是仍像角色海报。
- 景深：前中后景是否分开，焦点是否正确，背景是否可读而不过分抢眼。
- 光影：主光是否一眼可辨，阴影是否有信息，高光与反射是否服务视觉路径。
- 细节：只在镜头、空间和光影成立后补充；不能为修小细节而破坏已锁定的大结构。

优先级始终是：**镜头语言 → 构图 → 光影 → 景深 → 色彩 → 细节**。在同一轮中不要同时重写人物、构图、光线、色彩和服装；若问题属于更早的层级，回到该层级处理。
